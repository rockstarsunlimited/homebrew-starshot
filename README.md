# Homebrew tap for Starshot

This is the official Homebrew tap for [Starshot](https://github.com/rockstarsunlimited/starshot), a screenshot uploader for humans and automation.

## Install

```sh
brew tap rockstarsunlimited/starshot
brew install starshot
starshot setup
```

Run `starshot install` to install or refresh the **Starshot Upload** Finder Quick Action.

## Update

```sh
brew update
brew upgrade starshot
starshot install
```
